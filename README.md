A 3D horror multiplayer game.  This game features a flashlight that has battery usage and enemies that will track the player and roam around the map.  The main objective is to find enough banishment items to remove all of the ghosts from the game.

To run the game, access the zip folder within Github and run the executable within it, which should be called “Fading Light”.  To build and run the game, open the Unity editor and go to File → Build and Run.
